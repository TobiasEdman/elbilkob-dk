# Elbilkøb i Danmark — beslutningsstøtte

Interaktivt værktøj til at sammenligne to brugte elbiler i Danmark:
ejeromkostninger (værditab, rente, el, forsikring, service, grøn ejerafgift),
batterigaranti, markedspriser (AutoUncle.dk-øjebliksbillede) og modelanmeldelser.

**Live:** https://tobiasedman.github.io/elbilkob-dk/

Selvstændig `index.html` — al CSS/JS/data er inline, ingen server nødvendig.
Markedsdata er et øjebliksbillede (2026-07) og opdateres ikke automatisk.
